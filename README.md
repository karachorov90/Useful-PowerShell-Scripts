PowerShell scripts ps1 and exe version for Windows that some may find useful.
.NET and build in Windows UI only.

1. SysMon - Real time resources monitoring.
2. WinInfo - Gets Windows info like build, version etc. with one click
3. SysInfo - Gets system info like RAM, CPU, Storage.
4. OfficeInfo - Gets your installed Microsoft office info like version, build etc.

5. There is a notepad with PowerShell command for creating shortcut to the ps1 file because some antivirus software may take the exe as a thread, it works perfect like this. Can be stored on a server for example with shortcut on the hosts.
